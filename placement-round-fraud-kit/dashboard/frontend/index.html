About this system

"Risk" on this dashboard means pattern-consistency with an unsupervised anomaly ensemble (Isolation Forest, Local Outlier Factor, One-Class SVM, Elliptic Envelope), not a verified, investigator-confirmed fraud outcome — this dataset carries no ground-truth fraud label. The supervised XGBoost model was trained to reproduce that ensemble's own judgment, so strong feature attribution here confirms internal consistency, not necessarily real-world causal drivers of fraud.

The dataset is also far smaller than the ~1M rows a production deployment would see (2,512 transactions, 495 accounts), and the 5% contamination rate used to tune the anomaly detectors is a documented assumption, not a measured fraud rate. Before any production use: validate against investigator-labeled cases, and re-tune thresholds against the bank's real cost-of-fraud figures.
